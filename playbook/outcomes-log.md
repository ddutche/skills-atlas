# Outcomes Log

Plain-language running log of real attempts and what happened. Keep this loose and easy to add
to; do not over-formalize until there's enough here to need it. Newest first.

Entry format:

```
### {YYYY-MM-DD} {who/what}
- **Pattern/signal used:** which playbook entry, if any
- **What happened:** won / lost / no response / objection raised, and the short story
- **Takeaway:** anything worth feeding back into knowledge/ or playbook/
```
