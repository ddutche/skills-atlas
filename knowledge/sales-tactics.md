# Sales Tactics

Durable patterns about what works and doesn't in outreach, discovery, and pitching. One entry
per pattern. Newest first.

Entry format:

```
### {YYYY-MM-DD} {short title}
- **Insight:** the actual learning, stated plainly
- **Source:** file / conversation / research
- **Confidence:** observed / inferred / researched
- **Action implication:** what this suggests doing differently
```
